Läsrollen api-readonly

Chartet skapar Postgres-rollen som kontrollen avepoint-run-check loggar in med. I dag skapar chartet bara lösenordet. Rollen har aldrig funnits, så kontrollen har fallit varje morgon sedan minst 2026/10/03.

I dag password authentication failed for user "api-readonly", kl. 06:15 UTC varje dag. Hemligheten api-postgres-readonly-auth finns sedan 2026/08/11. Rollen finns inte.
Efter ändringen Rollen skapas eller uppdateras vid varje helm install och helm upgrade. Den kan bara läsa schemat avepoint.

1. Nyckel i values.yaml

# values.yaml
api:
  postgres:
    readonlyRole:
      enabled: false        # staging: true
  avepointRunCheck:         # fråga 2: flytta in kontrollen i chartet
    enabled: false          # staging: true
    schedule: "15 6 * * *"  # UTC, efter insamlingen kl. 06:00

2. Helm-jobbet

Ett jobb med hooken post-install,post-upgrade kör postgres:17 och loggar in som api över TLS (sslmode=verify-full, mot IssAssists CA). Lösenordet hämtas från hemligheten via secretKeyRef och skickas till psql som en variabel. Det syns aldrig på kommandoraden eller i loggen.

-- ett misslyckat ALTER ROLE får inte skriva lösenordet i Postgres-loggen
SET log_min_error_statement = panic;
DO $$BEGIN IF NOT EXISTS (SELECT FROM pg_roles WHERE rolname='api-readonly')
  THEN CREATE ROLE "api-readonly"; END IF; END$$;
ALTER ROLE "api-readonly" LOGIN NOSUPERUSER NOCREATEDB NOCREATEROLE NOREPLICATION
  NOBYPASSRLS CONNECTION LIMIT 3 PASSWORD :'ro_password';
GRANT CONNECT ON DATABASE api TO "api-readonly";
GRANT USAGE  ON SCHEMA avepoint TO "api-readonly";
GRANT SELECT ON ALL TABLES IN SCHEMA avepoint TO "api-readonly";
ALTER DEFAULT PRIVILEGES FOR ROLE api IN SCHEMA avepoint
  GRANT SELECT ON TABLES TO "api-readonly";

3. Vad rollen kommer åt

SchemaÅtkomstVarför
avepointSELECTDet enda som kontrollen läser: körningar, jobb och utbyten med AvePoint.
public, auth, tsm, kasten …ingenAnvändare, krypterade inloggningsuppgifter och andra kunders data nås inte.
skrivning, DDLingenRollen kan inte ändra något och får högst 3 samtidiga anslutningar.

4. Loggrader från jobbet

api-readonly: role ready; SELECT on 9 tables in schema avepoint

# ny installation, innan API:t har migrerat databasen:
schema avepoint not there yet (the API has not migrated); waiting…
schema avepoint still missing after 4 min; grants will be set on the next upgrade

Om schemat inte har kommit efter 4 minuter avslutas jobbet med en varning, inte med ett fel. En installation får aldrig misslyckas för kontrollens skull.
